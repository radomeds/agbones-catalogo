# Catálogo AG Bonés

Site e catálogo interativo da [AG Bonés](https://agbones.com.br) — fábrica de
bonés e chapéus personalizados em Caicó/RN, desde 2001.

O cliente escolhe o modelo, toca em cada parte da peça para dizer onde a arte
vai, e sai daqui com o pedido escrito, pronto para mandar no WhatsApp.

**No ar em:** https://radomeds.github.io/agbones-catalogo

## O que tem aqui

Só o site publicado: HTML, CSS e JavaScript puros, sem framework, sem etapa de
build e sem dependência externa. Todo o conteúdo do catálogo — modelos, fichas
técnicas, formas de aplicação, dúvidas — vive em `dados/produtos.json`.

Esta pasta é gerada a partir do repositório de trabalho, que é privado. Editar
aqui não adianta: a próxima publicação sobrescreve.
